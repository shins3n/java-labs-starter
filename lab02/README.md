# Лабораторная работа 2. Классы и инкапсуляция

## Инварианты

### BankAccount
1. Баланс не может быть отрицательным.
2. Пополнение возможно только на положительную сумму.
3. Снятие возможно только на положительную сумму и не превышающую баланс.
4. Баланс можно изменить только через `deposit` и `withdraw`.

### ProjectTask
1. `id` не null и не пустой.
2. `title` не null и не пустой.
3. `status` не null.
4. `estimatedHours` всегда положительное.
5. Статус меняется только через `changeStatus`.
6. Часы увеличиваются только через `increaseEstimatedHours` на положительное число.
7. Никаких сеттеров у полей нет.

## Поведение
- `changeStatus` — меняет статус задачи.
- `isCompleted` — возвращает true, если статус DONE.
- `increaseEstimatedHours` — увеличивает оценку трудоёмкости.
- `deposit` / `withdraw` — изменяют баланс с проверками.
