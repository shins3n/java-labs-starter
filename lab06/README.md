# Лабораторная работа 6. Коллекции и дженерики

## Обоснование выбора коллекций

1. **`Map<String, Integer>` (HashMap)** — используется для подсчета задач по статусам. `HashMap` обеспечивает быстрое добавление и получение по ключу за O(1).
2. **`Set<String>` (HashSet)** — используется для поиска уникальных категорий. `HashSet` автоматически отбрасывает дубликаты и быстро проверяет наличие элемента.
3. **`List<Task>` (ArrayList)** — используется для хранения исходного списка задач и для сортировки. `ArrayList` удобен для итерации и доступа по индексу.
4. **`Stack<T>`** — реализован на основе `ArrayList` (как требует задание). `ArrayList` удобен для добавления в конец (push) и удаления с конца (pop).
